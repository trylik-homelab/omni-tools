`astronaut.png` is the public-domain NASA photograph of astronaut Eileen Collins.
The unchanged 512×512 PNG comes from scikit-image 0.19.3:
https://github.com/scikit-image/scikit-image/blob/v0.19.3/skimage/data/astronaut.png

Source and public-domain status:
https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.astronaut

The OMNI-29 inference test uses the photo to check that background pixels become
transparent while the astronaut's face remains opaque.
